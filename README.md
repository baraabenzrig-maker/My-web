# Connect+

Connect+ is a simple social networking website prototype.

## Features

- Home page
- Create text posts
- Like posts
- User profile
- Change username
- Friends list
- Demo chat interface
- Responsive design for phones

## Files

- index.html
- style.css
- app.js
- login.html
- profile.html
- chat.html
- friends.html
- README.md

## How to run

Open index.html in a web browser.

## Important

This is a static website prototype.
Data is stored locally in the browser using localStorage.

It does not include a real online database,
real accounts, or communication between different users.
